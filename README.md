# 🚌 NYC MTA Bus Operational Efficiency & Performance Analysis using Distributed Computing

The New York City Metropolitan Transportation Authority (MTA) generates large-scale operational data from bus services, including passenger demand, waiting times, route performance, and congestion patterns. Efficient processing of this data is important for monitoring service reliability and supporting operational decision-making.

This project implements a **distributed data processing and analytics pipeline using AWS cloud technologies** to analyse NYC MTA bus operational data. The solution demonstrates how **parallel and distributed computing** can be applied to process transportation datasets efficiently while supporting scalable analytics and visualization.

The architecture uses **Amazon S3 for data storage, Amazon EMR with Apache Spark for distributed processing, Amazon Athena for analytical querying, and Microsoft Power BI for dashboard visualization**. PySpark applications were developed to perform **borough-level aggregation, route efficiency analysis, congestion and delay hotspot detection, and temporal trend analysis**.
